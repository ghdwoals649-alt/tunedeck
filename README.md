# TuneDeck

화면 오른쪽 가장자리에 반쯤 걸쳐 있는 **LP 위젯형 YouTube 플레이어**입니다.

- 평소에는 LP 절반만 화면 끝에 살짝 보여요. 재생 중이면 LP가 33⅓rpm으로 돌아가요.
- LP를 클릭하면 LP가 튀어나오고 그 아래로 영상, 컨트롤, 재생목록이 펼쳐져요.
- 배경은 지금 재생 중인 곡의 표지를 블러 처리한 이미지예요.
- 유튜브 링크를 붙여넣으면 재생목록에 추가돼요.

## 설치 (처음 한 번)

1. zip을 우클릭 → **압축 풀기(모두 추출)** 합니다.
2. `build.bat`을 더블클릭합니다. (Node.js 필요 없음, 인터넷만 연결돼 있으면 돼요)
3. 끝나면 열리는 폴더의 **TuneDeck.exe**를 실행합니다. 바탕화면 바로가기도 생겨요.

> SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요. 직접 빌드한 앱이라 서명이 없어서 나오는 경고입니다.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 펼치기 / 접기 | LP 클릭 / 오른쪽 위 `>` 버튼 또는 `Esc` |
| LP 위치 옮기기 | 접힌 LP를 위아래로 끌기 |
| 곡 추가 | 링크 칸에 붙여넣고 "추가". 창이 켜진 상태에서 그냥 `Ctrl+V`, 또는 브라우저에서 링크를 끌어다 놓기 |
| 재생목록 통째로 추가 | `youtube.com/playlist?list=...` 링크 붙여넣기 |
| 곡 재생 / 빼기 | 목록에서 클릭 / 마우스를 올리면 나오는 × |
| 순서 바꾸기 | 목록에서 끌어서 놓기 |
| 셔플 / 반복 | 컨트롤 양 끝 버튼 (반복: 전체 → 한 곡 → 안 함) |
| 재생 / 일시정지 | `Space`, 키보드 미디어 키, 또는 `Ctrl+Alt+P` (어디서든) |
| 다음 / 이전 곡 | `Ctrl+Alt+→` / `Ctrl+Alt+←` (어디서든) |
| 종료, 항상 위에, 자동 실행 | 작업표시줄 오른쪽 트레이 아이콘 우클릭 |

재생목록과 설정은 자동 저장돼서 다음에 켜도 그대로예요.

## 알아둘 점

- YouTube 정책상 플레이어 영상이 화면에 보여야 해서, 펼친 화면에 작은 영상 창이 있어요.
- 업로더가 외부 재생을 막아 둔 일부 공식 뮤직비디오는 재생되지 않아요. 이런 곡은 줄이 그어지고 다음 곡으로 넘어가요. 같은 곡의 "Topic"(자동 생성) 채널 버전이나 가사 영상 링크는 보통 잘 재생돼요.
- 광고 차단이나 음원 다운로드 기능은 넣지 않았습니다.
- TuneDeck은 Google/YouTube와 관계없는 비공식 앱입니다.

## 개발자용

```
npm install
npm start          # 바로 실행
npm run pack:win   # dist 폴더에 TuneDeck.exe 생성
```

- `main.js` 창, 도킹, 트레이, 저장
- `preload.js` 화면과 메인 프로세스 연결
- `renderer/` LP 화면 (index.html, style.css, app.js)
