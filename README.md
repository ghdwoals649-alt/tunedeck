# TuneDeck

화면 어디에나 놓아둘 수 있는 **카세트테이프 위젯형 YouTube 플레이어**입니다. (소리만 재생)

- 평소에는 작은 카세트 하나만 화면에 떠 있어요. 끌어서 원하는 곳에 둘 수 있어요. 재생 중이면 릴이 돌고, 진행에 따라 감긴 테이프 양이 바뀌어요.
- 카세트를 클릭하면 데크에 꽂히면서 아래로 영상, 컨트롤, 재생목록이 펼쳐져요.
- 곡이 바뀌면 테이프를 꺼내고 새 테이프를 넣는 장면이 나와요.
- 배경은 지금 재생 중인 곡의 표지를 블러 처리한 이미지예요.
- 노래·가수로 검색하거나 유튜브 링크를 붙여넣어 추가해요.
- 새 버전은 GitHub에서 자동으로 받아와요.

## 검색용 API 키 (처음 한 번)

1. https://console.cloud.google.com 에 Google 계정으로 로그인 → 새 프로젝트 만들기
2. "YouTube Data API v3" 검색 → **사용** 클릭
3. 왼쪽 메뉴 "사용자 인증 정보" → **사용자 인증 정보 만들기 → API 키**
4. 만들어진 `AIza...` 키를 TuneDeck 검색 결과 탭의 입력칸에 붙여넣기

무료이며 하루 약 100번 검색할 수 있어요.

## 설치 (처음 한 번)

1. zip을 우클릭 → **압축 풀기(모두 추출)** 합니다.
2. `build.bat`을 더블클릭합니다. (Node.js 필요 없음, 인터넷만 연결돼 있으면 돼요)
3. 끝나면 열리는 폴더의 **TuneDeck.exe**를 실행합니다. 바탕화면 바로가기도 생겨요.

> SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요. 직접 빌드한 앱이라 서명이 없어서 나오는 경고입니다.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 펼치기 / 접기 | 카세트 클릭 / 오른쪽 위 `>` 버튼 또는 `Esc` |
| 위치 옮기기 | 접힌 카세트를 끌기 (펼친 상태에선 위쪽 빈 곳이나 카세트를 끌기) |
| 곡 검색 | 검색칸에 노래·가수 입력 → 결과 클릭은 바로 재생, + 는 재생목록에 추가 |
| 링크로 추가 | 링크 칸에 붙여넣고 "추가". 창이 켜진 상태에서 그냥 `Ctrl+V`, 또는 브라우저에서 링크를 끌어다 놓기 |
| 재생목록 통째로 추가 | `youtube.com/playlist?list=...` 링크 붙여넣기 |
| 곡 재생 / 빼기 | 목록에서 클릭 / 마우스를 올리면 나오는 × |
| 순서 바꾸기 | 목록에서 끌어서 놓기 |
| 셔플 / 반복 | 컨트롤 양 끝 버튼 (반복: 전체 → 한 곡 → 안 함) |
| 재생 / 일시정지 | `Space`, 키보드 미디어 키, 또는 `Ctrl+Alt+P` (어디서든) |
| 다음 / 이전 곡 | `Ctrl+Alt+→` / `Ctrl+Alt+←` (어디서든) |
| 종료, 항상 위에, 자동 실행 | 작업표시줄 오른쪽 트레이 아이콘 우클릭 |

재생목록과 설정은 자동 저장돼서 다음에 켜도 그대로예요.

## 알아둘 점

- 영상은 보이지 않고 소리만 재생돼요. YouTube API 정책은 원래 플레이어가 화면에 보이는 것을 전제로 하므로, 개인용으로만 쓰세요.
- 업로더가 외부 재생을 막아 둔 일부 공식 뮤직비디오는 재생되지 않아요. 이런 곡은 줄이 그어지고 다음 곡으로 넘어가요. 같은 곡의 "Topic"(자동 생성) 채널 버전이나 가사 영상 링크는 보통 잘 재생돼요.
- 광고 차단이나 음원 다운로드 기능은 넣지 않았습니다.
- TuneDeck은 Google/YouTube와 관계없는 비공식 앱입니다.

## 개발자용

```
npm install
npm start          # 바로 실행
npm run pack:win   # dist 폴더에 TuneDeck.exe 생성
```

- `main.js` 창, 도킹, 트레이, 저장
- `preload.js` 화면과 메인 프로세스 연결
- `renderer/` LP 화면 (index.html, style.css, app.js)
